## Featured Project

### Project 01 — Customer Churn Analysis

**End-to-End Data Analytics Project | Python | SQL | PostgreSQL | Power BI**

An end-to-end customer churn analytics project focused on identifying churn-associated customer segments, analyzing customer risk, quantifying recurring revenue exposure, and identifying potential retention opportunities.

### Project Workflow

```text
Business Problem
      ↓
Data Validation
      ↓
Data Cleaning
      ↓
Python EDA
      ↓
KPI Analysis
      ↓
SQL / PostgreSQL Analysis
      ↓
Risk Segmentation
      ↓
Revenue Analysis
      ↓
Power BI Dashboard
      ↓
Business Insights
      ↓
Retention Recommendations
```

### Key Results

- **7,032 customers** analyzed after data cleaning
- **26.58%** overall observed churn rate
- **42.71%** observed churn among month-to-month customers
- **45.29%** observed churn among Electronic Check customers
- **47.68%** observed churn among customers with 0–12 months tenure
- **74.45%** observed churn at Risk Score 6
- **910** high-value churned customers identified
- **139.13K** in monthly charges associated with churned customers
- **1,182** active customers in high-risk segments
- **89.89K** in associated monthly revenue among high-risk active customers
